# 🐾 PawPals Pet Care Center

A clean, modern, and responsive pet care center website designed with warm aesthetics, friendly user experience, and authentic human-crafted code. Built with semantic **HTML5**, modern **Vanilla CSS**, and lightweight **Vanilla JavaScript**.

---

## 🌟 Key Features

- **Warm, Welcoming Aesthetic**: Built with soft organic tones (cream, warm amber, sage green) avoiding harsh dark modes and robotic artificial gimmicks.
- **Full Pet Care Services**:
  - ✂️ **Pet Grooming** (Styling, de-shedding, nail filing, ear cleaning)
  - 🛁 **Pet Bathing** (Warm hydrobath, hypoallergenic shampoos, fluff blow dry)
  - 🦮 **Pet Walking** (Structured exercise routes, hydration, GPS updates)
  - 🏡 **Pet Sitting & Daycare** (Supervised 100% cage-free play areas)
  - 🩺 **Basic Pet Care & Wellness** (Dietary schedules, medication, wellness checks)
- **Clear Pricing in Indian Rupees (₹)**:
  - Essential Refresh: **₹699** / session
  - Full Spa & Pamper: **₹1,499** / session
  - Daycare & Adventure: **₹899** / day
  - Overnight Boarding: **₹1,299** / night
- **Interactive Pet Information Center**:
  - Filter by pet type (**Dogs, Cats, Rabbits, Birds, Other small pets**) with customized care requirements and handling tips.
- **Interactive Booking Form**:
  - Validates owner contact info, pet details, preferred service, date, and care notes.
  - Generates instant client-side booking reference code (`#PAW-2026-XXXX`) with a popup receipt modal.
- **Trust & Verification**:
  - Verified partnership and accredited safety compliance with **petinfo.trust.com**.
- **Contact & Operating Hours**:
  - Full weekly drop-off schedule, direct phone lines, and official Gmail contact channels (`pawpalscare@gmail.com`).

## 🚀 Live Demo & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Mohammedfaiz-1010/Pet-care-project.git
   ```

2. **Open the project**:
   - Double-click `index.html` to open directly in any web browser (Chrome, Edge, Firefox, Safari).
   - Or run a local HTTP server:
     ```bash
     python -m http.server 8080
     ```
     and visit `http://localhost:8080`.

## 🌐 GitHub Pages Deployment

To enable free hosting on GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/Mohammedfaiz-1010/Pet-care-project`
2. Click **Settings** → **Pages** (left sidebar).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at:
   `https://mohammedfaiz-1010.github.io/Pet-care-project/`
